# AI SEO — Detailed Specification

Serve a truthful `llms.txt` listing key pages with accurate one-line summaries; never
fabricate entries. Emit valid Schema.org JSON-LD whose values match the visible content, and
keep site-wide entities (Organization, Person, Product) consistent across pages. Structure
facts in semantic elements — lists, tables, definition lists — under clear, question-shaped
headings so answer engines can extract and cite them. Authoritative source: AS-010 (AI-SEO
standard).
