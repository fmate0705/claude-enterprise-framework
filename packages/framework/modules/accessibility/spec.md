# Accessibility — Detailed Specification

Interactive elements are real semantic controls (`button`, `a`) with reachable, visible
focus — never styled `div`s. Text meets AA contrast (4.5:1 body, 3:1 large). Every flow is
fully keyboard operable with a logical focus order and no traps. Images carry meaningful or
intentionally empty `alt`; icon-only controls have accessible names; dynamic status is
announced. Never convey meaning by color alone. Accessibility is a non-negotiable floor.
Authoritative source: AS-012 (Accessibility).
