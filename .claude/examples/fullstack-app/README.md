# Example — Full-Stack App

**Purpose:** Serve as a reference implementation of a full-stack application built end-to-end to CEF standards.

**Description:** This example will be a complete data-backed application demonstrating how CEF handles the whole stack: UI, server logic, database, authentication, testing, containerization, and deployment. It shows the `fullstack` archetype taken to a secure, tested, deployable result — the most comprehensive proof of CEF's end-to-end discipline.

## What this example will demonstrate

- A working UI + API + data layer per the architecture standard.
- Secure authentication and sessions per the security standard.
- Meaningful test coverage per the testing standard.
- Docker and deployment configuration passing the deployment and release checklists.
