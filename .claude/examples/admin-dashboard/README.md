# Example — Admin Dashboard

**Purpose:** Serve as a reference implementation of a data-dense admin dashboard built end-to-end to CEF standards.

**Description:** This example will be a complete admin/analytics dashboard demonstrating how CEF handles density with clarity: navigation, accessible data tables and charts, filtering, and detail views that stay fast and legible under real data. It shows the `dashboard` archetype taken to a finished, usable result.

## What this example will demonstrate

- A dashboard shell with real data-view patterns.
- Accessible tables, charts, and filters per the UI and accessibility standards.
- Performance under load per the performance standard.
- Passing accessibility and performance checklists.
