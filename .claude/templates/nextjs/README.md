# Next.js Template

**Purpose:** Provide the opinionated starting scaffold for a Next.js application built to CEF standards.

**Description:** This template is CEF's default web application scaffold. When authored, it will contain a preconfigured Next.js (App Router) project wired to the architecture, Next.js, React, TypeScript, design, and performance standards — strict TypeScript, sensible directory structure, base design tokens, and quality tooling — so a new project starts compliant instead of being retrofitted.

## Intended contents

- App Router structure per the Next.js standard.
- Strict TypeScript configuration.
- Base design tokens and UI primitives.
- Linting, formatting, and testing preconfigured.

## Status

Scaffold (AS-000). The template files will be authored in a later module.
