# Agency Template

**Purpose:** Provide the opinionated starting scaffold for an agency or studio website — services, work, and lead capture — built to CEF standards.

**Description:** This template targets agencies, studios, and consultancies that sell services and showcase work. When authored, it will contain a preconfigured scaffold wired to the design, motion, copywriting, SEO, AI-SEO, performance, and accessibility standards — services, case studies, team, and contact — balancing distinctive craft with the discipline to convert visitors into leads.

## Intended contents

- Services, case-study/portfolio, team, and contact sections.
- Distinctive-but-disciplined design and motion.
- SEO/AI-SEO foundation and lead-capture flows.
- Accessible, performant, responsive layout.
