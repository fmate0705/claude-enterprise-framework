# Full-Stack Template

**Purpose:** Provide the opinionated starting scaffold for a full-stack application (frontend + backend + data) built to CEF standards.

**Description:** This template targets applications that need server logic, a database, and authentication alongside the UI. When authored, it will contain a preconfigured full-stack project wired to the architecture, Next.js, TypeScript, security, testing, and deployment standards — including data-access patterns, auth scaffolding, and containerization — so a data-backed product starts on solid, secure footing.

## Intended contents

- Full-stack structure (UI, API/server, data layer).
- Authentication and session scaffolding per the security standard.
- Database access patterns and migrations.
- Docker and deployment configuration.
