# React Template

**Purpose:** Provide the opinionated starting scaffold for a client-side React application built to CEF standards.

**Description:** This template targets single-page React applications that do not need a full meta-framework. When authored, it will contain a preconfigured React + TypeScript project wired to the architecture, React, TypeScript, design, and performance standards, with routing, base tokens, and tooling in place — a clean, compliant starting point for interactive apps.

## Intended contents

- React + TypeScript project with strict configuration.
- Client-side routing and application structure.
- Base design tokens and UI primitives.
- Linting, formatting, and testing preconfigured.

## Status

Scaffold (AS-000). The template files will be authored in a later module.
