# SaaS Template

**Purpose:** Provide the opinionated starting scaffold for a SaaS product — marketing surface plus application shell — built to CEF standards.

**Description:** This template targets software products that pair a marketing/pricing site with an authenticated app. When authored, it will contain a preconfigured project wired to the architecture, Next.js, TypeScript, security, performance, and deployment standards — marketing pages, auth, an app shell, settings, and billing scaffolding — so a SaaS starts credible to prospects and solid for users.

## Intended contents

- Marketing surface (home, features, pricing) and app shell (dashboard, settings).
- Authentication, sessions, and account management per the security standard.
- Billing/subscription scaffolding.
- Deployment and environment configuration.

Scaffold (AS-000). The template files will be authored in a later module.
