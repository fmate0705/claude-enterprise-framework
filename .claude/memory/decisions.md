# Decisions Memory

**Purpose:** Maintain a durable log of significant decisions and their rationale — a lightweight architecture decision record for the project.

**Description:** This file is the project's decision log. Whenever a meaningful choice is made — a library, a pattern, a trade-off, a deviation from a standard — it is recorded here with the reasoning and the alternatives considered. It prevents decisions from being silently reversed and gives future sessions the *why*, not just the *what*. Entries are append-only and dated.

## Format

Each entry:

```
### [YYYY-MM-DD] <Decision title>
- **Decision:** what was decided
- **Context:** what prompted it
- **Alternatives considered:** what else was weighed
- **Rationale:** why this option won
```
