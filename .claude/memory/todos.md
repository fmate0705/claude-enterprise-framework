# Todos Memory

**Purpose:** Track the outstanding work for the current project — the living task list that drives the implementation loop.

**Description:** This file holds the project's task backlog and in-flight work. It is populated during planning with sequenced tasks and acceptance criteria, and worked down during implementation. It is the source of truth for "what's next," and it stays in sync with session memory. Completed items are checked off (or archived) so the file always reflects reality.

## Format

- Group tasks by workflow phase or feature area.
- Each task carries a clear acceptance criterion.
