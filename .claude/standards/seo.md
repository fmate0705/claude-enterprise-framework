# SEO Standard

**Purpose:** Define how CEF makes sites discoverable and rankable by traditional search engines — metadata, structure, performance, and content signals.

**Description:** SEO is an engineering concern in CEF, not a marketing afterthought. This standard will prescribe semantic HTML structure, title and meta description conventions, canonical URLs, structured data (schema.org), sitemap and robots handling, Open Graph and Twitter cards, internationalization signals, and the performance factors that feed Core Web Vitals. It coordinates with the performance and accessibility standards, since fast, accessible, semantic pages rank best.

## Scope

- Semantic document structure and heading hierarchy.
- Title, meta, canonical, and Open Graph/Twitter metadata.
- Structured data (JSON-LD / schema.org).
- Sitemaps, robots, and crawlability.
- Core Web Vitals as ranking signals.

## Status

**Superseded by the Discoverability Engine (AS-010).** The canonical SEO standard now lives in [`discoverability/`](discoverability/); read that directory for all SEO and discoverability decisions.
