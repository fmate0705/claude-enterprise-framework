# The Definition of Premium

**Framework:** CEF · **Specification:** AS-008 (Experience Engine) · **Version:** 0.1.0

**Purpose:** State precisely what "premium" means in design terms, so it can be produced deliberately and verified. This elaborates Constitution Article III for the design surface.

**Language:** MUST / MUST NOT / SHOULD / MAY per RFC 2119.

---

## Premium Is Trust, Not Beauty

Premium is the immediate perception of quality, clarity, credibility, and professionalism. It is produced by reducing cognitive load, increasing confidence, and guiding attention intentionally. Beauty is a by-product; trust is the objective.

Premium does **not** mean expensive, flashy, animated, or maximal. It is frequently the quietest interface in the room.

## What Premium Requires

A premium interface MUST satisfy all of the following. Each is verifiable at review (`review.md`).

| Property | Requirement |
|---|---|
| **Clear** | The primary message and action are understood within seconds; nothing competes for the same attention. |
| **Legible** | Type, contrast, and measure make reading effortless; the eye always knows where to go next. |
| **Ordered** | A single, obvious visual hierarchy directs attention deliberately. |
| **Spacious** | Whitespace is used as structure; content breathes and groups by proximity. |
| **Consistent** | Tokens, spacing, type, and patterns are uniform, so the whole feels made by one mind. |
| **Fast** | The interface responds immediately and loads within budget; speed is felt as quality first. |
| **Honest** | Content is real; claims are true; nothing is faked or manipulative. |
| **Accessible** | It works for every user; exclusion is a defect, never a trade for aesthetics. |
| **Restrained** | Only what earns its place remains; decoration for its own sake is removed. |
| **Timeless** | It favors durable design over trend; novelty is spent only for real advantage. |

## How Premium Is Perceived

- **PRM-01 — First impression is hierarchy.** Within the first seconds, a user MUST be able to identify the single most important message and action. A view with no clear focal point MUST NOT ship.
- **PRM-02 — Credibility is cumulative.** Trust is built by many correct details (alignment, spacing, real content, working links) and destroyed by a few wrong ones. Details MUST compound, not contradict.
- **PRM-03 — Cognitive load is the enemy.** Every choice, every competing element, and every ambiguous label increases load. The design MUST minimize decisions and remove noise.
- **PRM-04 — Consistency reads as competence.** Inconsistent spacing, type, or color signals carelessness. Uniformity MUST be maintained across the whole product.
- **PRM-05 — Restraint signals confidence.** A calm, sparse interface signals a product sure of its value; visual clutter signals the opposite. Restraint MUST be the default.

## Premium Guarantees

- **PRM-G1** — Every interface has one clear hierarchy and one primary action per view.
- **PRM-G2** — Content is real, legible, and honest; nothing is faked.
- **PRM-G3** — Consistency, spaciousness, and restraint are maintained throughout.
