# Visual Rhythm

**Framework:** CEF · **Specification:** AS-008 (Experience Engine) · **Version:** 0.1.0

**Purpose:** Fix the rhythm and pacing of a page. Consistent rhythm is calming and legible; a page MUST guide the eye with alternating density and rest.

**Language:** MUST / MUST NOT / SHOULD / MAY per RFC 2119.

---

## Rhythm Rules

- **VR-01 — Consistent vertical rhythm.** Vertical spacing MUST follow the rhythm scale (`spacing.md`); erratic gaps between sections MUST NOT be used.
- **VR-02 — Section cadence.** Sections MUST use consistent, equal vertical padding so the page has a steady cadence (`spacing.md` SP-04).
- **VR-03 — Density alternation.** A page MUST alternate denser and lighter sections to create pacing and rest; a uniform density that fatigues the eye MUST NOT be used.
- **VR-04 — Baseline rhythm.** Text MUST sit on a consistent baseline rhythm (line-height and spacing on the scale).
- **VR-05 — Repetition sets tempo.** Repeated components MUST keep consistent spacing to set a predictable tempo (`composition.md` CO-08).
- **VR-06 — Rest points.** Whitespace MUST provide rest points between dense areas; content MUST NOT run without pause.
- **VR-07 — Entrance pacing.** Where motion is used, it MUST reinforce rhythm (staggered, brief) and MUST honor reduced-motion; motion MUST NOT disrupt pacing (`principles.md` XP-P09).
- **VR-08 — Scroll pacing.** The page MUST pace the scroll so each section is a distinct, digestible unit; sections MUST NOT blur together.

## Rhythm Guarantees

- **VR-G1** — Consistent vertical rhythm and section cadence.
- **VR-G2** — Density alternates with rest to guide the eye.
- **VR-G3** — Repetition sets a predictable tempo.
