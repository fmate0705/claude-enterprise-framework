# Review Standard

**Purpose:** Define how CEF reviews its own work — what a self-review covers, the severity model, and the bar code must clear before it is considered done.

**Description:** CEF holds that no code is complete until it has been reviewed against the standards. This document will define the review discipline: correctness, adherence to every applicable standard, security, performance, accessibility, and readability. It will establish a severity model (blocker, major, minor, nit), require that review findings are resolved or explicitly waived, and connect review to the review workflow and checklists. Review is not a formality — it is the gate that makes CEF quality real.

## Scope

- What every review must check (correctness, standards adherence, security, a11y, performance).
- Severity model and how findings are triaged and resolved.
- Self-review discipline vs. human review.
- How review integrates with the review workflow and checklists.
- Sign-off criteria: what "reviewed" means.
