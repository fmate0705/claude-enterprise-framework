# Storytelling

**Framework:** CEF · **Specification:** AS-011 (Content Intelligence Engine) · **Version:** 0.1.0

**Purpose:** Fix how narrative structures a page so the reader moves from problem to resolution. Storytelling serves clarity and persuasion; it MUST NOT become fiction.

**Language:** MUST / MUST NOT / SHOULD / MAY per RFC 2119.

---

## Storytelling Rules

- **STY-01 — Reader is the hero.** The narrative MUST center the reader and their problem; the brand is the guide, not the hero (`CNP-08/CNP-38`).
- **STY-02 — Problem first.** A persuasive page SHOULD open by naming the reader's problem or goal before presenting the solution.
- **STY-03 — Clear arc.** The page MUST follow a coherent arc — problem → solution → proof → outcome → action; disjointed sections MUST NOT be used (`page-structure.md`).
- **STY-04 — Show the outcome.** The narrative MUST make the "after" state concrete (what changes for the reader); vague transformation claims MUST NOT be used.
- **STY-05 — Proof in the story.** Claims in the narrative MUST be supported by real proof (examples, data, case studies); invented stories MUST NOT be used (`trust-signals.md`).
- **STY-06 — One thread.** A page MUST hold one clear narrative thread; competing messages MUST NOT dilute it (`experience/hierarchy.md`).
- **STY-07 — Pace with structure.** The story MUST be paced with headings, sections, and whitespace so it is scannable (`experience/visual-rhythm.md`).
- **STY-08 — Honest emotion.** Emotional appeals MUST be honest and relevant; manufactured urgency or fear MUST NOT be used (`CNP-16`).
- **STY-09 — Resolve to action.** The narrative MUST resolve into a clear next action (`calls-to-action.md`).
- **STY-10 — Real cases only.** Customer stories MUST be real and used with permission; fabricated narratives MUST NOT be published (`case-studies.md`).

## Storytelling Guarantees

- **STY-G1** — Reader-centered arc from problem to action.
- **STY-G2** — Concrete outcomes supported by real proof.
- **STY-G3** — One honest thread; no fabricated stories.
