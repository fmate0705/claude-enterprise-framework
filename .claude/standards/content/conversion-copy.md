# Conversion Copy

**Framework:** CEF · **Specification:** AS-011 (Content Intelligence Engine) · **Version:** 0.1.0

**Purpose:** Fix how copy persuades honestly. Conversion is earned by clarity and credibility, never manipulation. This aligns with the Experience Engine's conversion design (`experience/conversion.md`).

**Language:** MUST / MUST NOT / SHOULD / MAY per RFC 2119.

---

## Conversion Copy Rules

- **CVC-01 — Hero messaging.** The hero MUST state, in the headline, what the product does and for whom, plus the primary benefit; vague or clever-only heroes MUST NOT be used (`headlines.md`).
- **CVC-02 — Value proposition.** A clear value proposition MUST state the outcome, the audience, and the differentiator; a generic mission statement MUST NOT stand in for it.
- **CVC-03 — Benefits before features.** Copy MUST translate features into user benefits; a raw feature list without benefit MUST NOT lead (`copywriting.md` CW-01).
- **CVC-04 — Objection handling.** Common objections (price, effort, risk, trust) MUST be addressed directly in copy ("No credit card required", "Cancel anytime").
- **CVC-05 — Social proof.** Real, attributed proof (testimonials, logos, metrics) MUST support claims near decision points; fabricated proof MUST NOT be used (`trust-signals.md`).
- **CVC-06 — Ethical urgency.** Urgency and scarcity MUST be real (a genuine deadline or limited stock); fake countdowns and invented scarcity MUST NOT be used (`CNP-16`).
- **CVC-07 — Trust indicators.** Trust signals (guarantees, security, transparency) MUST be honest and specific; vague reassurance MUST NOT substitute.
- **CVC-08 — CTA writing.** CTAs MUST be verb-led and value-clear (`calls-to-action.md`); weak CTAs MUST NOT be used.
- **CVC-09 — Pricing communication.** Pricing copy MUST be transparent — what is included, what it costs, and any conditions; hidden costs and confusing tiers MUST NOT be used (`page-structure.md` pricing).
- **CVC-10 — Lead generation.** Lead-capture copy MUST state the value exchange and request the minimum; dark patterns MUST NOT be used (`ux-writing.md`, `experience/forms.md`).
- **CVC-11 — Clarity over persuasion.** Where clarity and cleverness conflict, clarity MUST win; persuasion MUST NOT obscure the offer (`CNP-27`).
- **CVC-12 — Honest claims only.** Every conversion claim MUST be true and supportable (`CNP-16/CNP-22`).

## Conversion Copy Guarantees

- **CVC-G1** — Clear value proposition, benefit-led, with real proof.
- **CVC-G2** — Objections handled; urgency and pricing honest.
- **CVC-G3** — Clarity over manipulation; no dark patterns or fabrication.
