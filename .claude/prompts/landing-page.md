# Landing Page Prompt

**Purpose:** Bootstrap a high-converting marketing landing page project under the full CEF standard.

**Description:** This prompt kicks off a single-page (or few-page) marketing site focused on a single conversion goal. When invoked, it will drive the discovery workflow to capture the offer, audience, and brand; select the `landing-page` template; and apply the design, copywriting, motion, SEO, AI-SEO, performance, and accessibility standards. The output target is a fast, persuasive, on-brand page with a clear call to action.

## What this prompt will produce

- A conversion-focused landing page built to CEF standards.
- A narrative arc: hook → value → proof → objection handling → CTA.
- Performance and accessibility within budget from the first build.

## Archetype notes

- Single primary conversion goal; minimize distractions.
- Copy leads; layout serves the copy.
- Heavy emphasis on above-the-fold clarity and speed.
