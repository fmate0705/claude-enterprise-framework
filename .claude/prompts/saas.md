# SaaS Prompt

**Purpose:** Bootstrap a SaaS product project — marketing site plus application shell — under the full CEF standard.

**Description:** This prompt kicks off a software-as-a-service build spanning a marketing/pricing surface and an authenticated application. It drives discovery to capture the product, pricing, and personas, selects the `saas` template, and applies the architecture, Next.js, React, TypeScript, security, performance, accessibility, and deployment standards. The output target is a product foundation that is credible to prospects and solid for users.

## What this prompt will produce

- A marketing surface (home, features, pricing, docs) plus an app shell (auth, dashboard, settings).
- Secure authentication and session handling per the security standard.
- A deployable, scalable foundation ready to build features on.

## Archetype notes

- Two audiences: prospects and logged-in users — design for both.
- Pricing and onboarding are first-class flows.
- Security and architecture matter more here than on a static site.
