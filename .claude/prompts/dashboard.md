# Dashboard Prompt

**Purpose:** Bootstrap a data-dense admin or analytics dashboard under the full CEF standard.

**Description:** This prompt kicks off an internal or product dashboard focused on data density, clarity, and task efficiency. It drives discovery to capture the data, roles, and key tasks, selects the `dashboard` template, and applies the architecture, React, TypeScript, UI, accessibility, and performance standards. The output target is a dashboard where information is legible, actions are fast, and complexity is tamed by good layout.

## What this prompt will produce

- A dashboard shell with navigation, data views, tables, and detail panes.
- Accessible, performant data presentation (tables, charts, filters).
- Role-aware layout patterns.

## Archetype notes

- Density with clarity — hierarchy prevents overwhelm.
- Performance matters under large datasets.
- Keyboard and accessibility are critical for power users.
